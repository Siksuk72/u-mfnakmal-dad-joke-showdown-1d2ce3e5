One dad joke, in the dad's own voice, for the Dad Joke Showdown on
make.fun. A son asks for a trampoline for his birthday; the dad says no —
birthdays aren't about jumping to conclusions. The setup and the payoff
are the same object (the trampoline), so the pun lands on the very thing
he was asked for: a mundane request, a straight-faced refusal, and a
groan-worthy payoff that needs no explanation. Every word earns its
place, and the joke is over before the reader can brace for it — exactly
what the brief asks for.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (UTF-8, 1–200 characters).
